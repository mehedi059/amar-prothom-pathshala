# আমার প্রথম পাঠশালা — Full Project

৩–৬ বছর বয়সী শিশুদের জন্য Flutter Android learning app.

## Included
- বাংলা ৪৬টি, English ২৬টি, আরবি ২৮টি বর্ণ/শব্দের গ্রিড
- প্রতিটি কার্ডের জন্য নির্দিষ্ট male/female voice assignment
- ৫টি নিজস্ব ছোট বাংলা ছড়া এবং অডিও তৈরির স্ক্রিপ্ট
- GitHub Actions: MP3 তৈরি → Flutter release APK build → APK artifact
- MIT License; Developer: মো: মেহেদী হাসান

## Voice plan
Bangla (Bangladesh): `bn-BD-PradeepNeural` (male), `bn-BD-NabanitaNeural` (female).
English: US English voices. Arabic: Saudi Arabic voices.
Audio is generated by `scripts/generate_audio.py` during the GitHub Actions build, then bundled into the APK. Once generated and installed, lesson audio is played from local assets and does not require an internet connection.

## GitHub upload
1. Extract this ZIP.
2. Upload the CONTENTS of `Amar_Prothom_Pathshala_Full_Project` to the root of your GitHub repository (not the containing folder).
3. Commit to `main` (or `master`).
4. Open the repository's Actions tab and wait for “Generate Audio and Build APK” to finish.
5. Open the successful run, go to Artifacts, and download `amar-prothom-pathshala-apk`.

## Important
The GitHub workflow needs internet access to obtain the TTS audio and Flutter dependencies. The generated MP3 files are produced by the workflow, not pre-included in this ZIP. If Microsoft's speech endpoint or a voice is temporarily unavailable, the workflow may fail and can be rerun. Review pronunciations—especially Arabic and uncommon Bangla letters—before publishing for children.
