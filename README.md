# আমার প্রথম পাঠশালা (Amar Prothom Pathshala)

৩–৬ বছর বয়সী শিশুদের জন্য অফলাইন ইন্টারঅ্যাকটিভ শিক্ষামূলক Android অ্যাপের Flutter starter project।

## বর্তমান প্রোটোটাইপে যা আছে
- বাংলা বর্ণের নমুনা পাঠ
- English alphabet-এর নমুনা পাঠ
- প্রাথমিক গণিতের নমুনা
- আরবি হরফের নমুনা
- ছবি দেখে শেখা, ছড়া ও ইসলামিক শিক্ষার বিভাগ
- প্রতিটি পাঠের আলাদা স্ক্রিন
- MP3 অডিও যুক্ত করার প্লেয়ার
- GitHub Actions দিয়ে release APK build workflow

## চালানোর নিয়ম
1. Flutter SDK ইনস্টল করুন।
2. এই প্রজেক্ট GitHub repository-তে আপলোড করুন।
3. Android Studio অথবা VS Code-এ প্রজেক্ট খুলুন।
4. চালান:

```bash
flutter pub get
flutter run
```

## GitHub থেকে APK
1. Repository-তে `main` branch-এ কোড push করুন।
2. GitHub-এর **Actions** ট্যাব খুলুন।
3. **Build Android APK** workflow চালু/সম্পন্ন হতে দিন।
4. সফল হলে `amar-prothom-pathshala-apk` artifact থেকে APK ডাউনলোড করুন।

## মানুষের কণ্ঠের অডিও যোগ করা
অডিও ফাইলগুলো নির্দিষ্ট ফোল্ডারে রাখুন:

- বাংলা: `assets/audio/bn/`
- ইংরেজি: `assets/audio/en/`
- আরবি: `assets/audio/ar/`

উদাহরণ:
- `assets/audio/bn/ক.mp3`
- `assets/audio/en/a.mp3`
- `assets/audio/ar/alif.mp3`

ফাইলের নাম `main.dart`-এর Lesson ডেটার `audio` মানের সঙ্গে হুবহু মিলতে হবে।
রেকর্ডিং পরিষ্কার, ধীর, শিশু-বান্ধব এবং সঠিক উচ্চারণে করতে হবে।

## ছবি যোগ করা
বাস্তব ছবি ও কার্টুনের অনুমতিপ্রাপ্ত/নিজস্ব ছবি `assets/images/`-এ রাখুন।
বর্তমান প্রোটোটাইপে ইমোজি-ভিত্তিক অস্থায়ী ভিজ্যুয়াল আছে; পূর্ণ সংস্করণে এগুলো বিষয়ভিত্তিক ছবি দিয়ে প্রতিস্থাপন করতে হবে।

## গুরুত্বপূর্ণ
এই ZIP একটি কাজ-শুরুর উপযোগী Flutter source prototype; এটি এখনো সম্পূর্ণ বই বা চূড়ান্ত APK নয়। মানুষের কণ্ঠের রেকর্ডিং, পূর্ণ বর্ণমালা, সব অধ্যায়ের ছবি, কুইজ, অগ্রগতি সংরক্ষণ, অভিভাবক ড্যাশবোর্ড এবং চূড়ান্ত ডিভাইস-পরীক্ষা পরবর্তী ধাপে সম্পন্ন করতে হবে।
